# 🤖 MERN AI Chatbot

An AI-powered chatbot built using the **MERN Stack** and the **OpenAI API**. The application provides real-time AI conversations with a clean, responsive user interface and a secure backend.

---

## 🚀 Features

- 💬 Real-time AI Chat
- 🤖 OpenAI API Integration
- 🔒 Secure API Key using Environment Variables
- ⚡ Fast and Responsive UI
- 📱 Mobile Friendly Design
- 🎨 Clean User Interface
- 🌐 REST API Architecture

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Anish70509498/MERN-AI-Chatbot.git
```

### Move into Project

```bash
cd MERN-AI-Chatbot
```

### Install Dependencies

Backend

```bash
cd backend
npm install
```

Frontend

```bash
cd ../frontent
npm install
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **backend** folder.

```env
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
MONGO_URL=YOUR_MONGODB_CONNECTION_STRING
```

> Never commit your `.env` file or API keys to GitHub.

---

## ▶️ Run the Project

Backend

```bash
npm start
```

Frontend

```bash
npm run dev
```
